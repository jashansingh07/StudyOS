# StudyOS

AI Academic Mentor & Multi-Source Learning Platform

## Project

StudyOS is an AI-powered academic learning platform that helps
students understand their course materials, practice questions,
identify weaknesses, and create personalized study plans.

## Tech Stack

### Frontend
- Next.js
- TypeScript
- Tailwind CSS

### Backend
- FastAPI
- Python

### Database
- PostgreSQL

### AI / RAG
- LangChain
- ChromaDB
- LLM API
